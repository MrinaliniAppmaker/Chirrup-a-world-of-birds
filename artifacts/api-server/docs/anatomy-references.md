# Coot foot anatomy reference

The lobed-toe generation input uses a foot-only crop of **Coot feet.jpg** by
[Shyamal](https://commons.wikimedia.org/wiki/User:Shyamal), August 2014.

- Source: https://commons.wikimedia.org/wiki/File:Coot_feet.jpg
- Original: https://upload.wikimedia.org/wikipedia/commons/8/8a/Coot_feet.jpg
- License: [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)
- Modification: crop from the 1659 × 1383 original using SVG viewBox
  `600 300 990 650`, resized to 880 × 578 PNG. The crop excludes the bird's body,
  head and plumage and retains one foot, toe lobes, claws and a short leg stub.
  The cropped reference remains licensed CC BY-SA 3.0.
- Private App Storage object: `anatomy-references/coot-feet-shyamal-crop.png`.
  Object metadata also retains credit, source and license.

This is an internal anatomy-conditioning asset, not a selectable bird, a saved
journal portrait or an illustration displayed in the app. The generator must use
only the lateral lobe geometry and natural skin texture; all selected colors,
body parts and independently requested toe directions/counts remain authoritative.
Do not substitute a whole coot photograph or hotlink external images at runtime.
